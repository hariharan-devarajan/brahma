brahma
======

Brahma is a C++ interception library for application I/O calls. It uses
`GOTCHA <https://github.com/LLNL/GOTCHA>`_ to intercept POSIX, STDIO, MPI,
MPI-IO, and HDF5 calls through pluggable, class-based interfaces.
